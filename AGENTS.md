# Agent Instructions

## Feature implementation

Before any feature is implemented, comprehensive test should be written

The test should cover the work that the feature is solving

The test should initially fail and pass only when the feature is fully implemented

No test shall be modify unless explicitly specified

## Version Control

Do not create commits unless the user explicitly asks you to commit.

Before creating any commit or finalizing changes, make sure the code implemented can be complied and run test

Do not commit if any tests fail.

Run lint command to make sure the code is properly linted, before creating a commit

## Code changes

Before any code changes happen, the agent need to state the planned changes for approval
